# 离线婚礼桌位编排器

宾客关系与真实场地布局联合编排的纯离线应用：**React + TypeScript** 管理宾客侧栏与检查器，
**Konva** 绘制桌椅、通道与消防出口缓冲区，**glpk.js 在 Web Worker 中**求解
同桌 / 分桌 / 容量 / 锁定等约束，工程只保存在浏览器 **IndexedDB**，没有服务端。

## 运行

```bash
npm install
npm run dev          # 开发
npm run build        # 类型检查 + 生产构建
npm run test:logic   # 46 项离线逻辑验证（Node 直接跑 glpk.js，无需浏览器）
```

## 模型与规则

### 硬条件（必须满足，无解时求解器明确返回 infeasible）

| 约束 | 说明 |
| --- | --- |
| 家庭同行 `family` | 两名宾客所在桌完全相同（每桌一条等值线性约束） |
| 明确避让 `avoid` | 两名宾客不能同桌（每桌 `x[a,t]+x[b,t] ≤ 1`） |
| 容量 | 每桌人数（含儿童椅占位）≤ 桌容量 |
| 锁定座位 | 锁定者固定在原桌原位，锁定占用预先从容量中扣除，自动排座只填空位 |
| 婉拒 | 已婉拒宾客不参与排座，手工也无法安排 |
| 未回复 | 默认不进自动排座；勾选后才排入，且产生小幅软代价；手工始终可单独安排 |

### 软偏好（可放宽，未满足时累加代价并在界面显示）

- `preferNear` 希望同桌：未同桌计权重代价（默认 10）
- 靠近主桌 / 指定桌：按桌心距离分 4 档（同桌 0 / 紧邻 / 同区 / 远），代价 = 权重 × 档位（默认权重 6）
- 未回复宾客被排入：每人 1 点提示性代价

自动方案生成后**不会立即应用**，右侧显示「手工方案 vs 自动方案」代价对比卡，
可应用或放弃；应用动作也进入撤销栈（Ctrl/Cmd+Z 可退回手工版）。

### 同名宾客

同名宾客按创建顺序获得稳定编号（`张伟 #1` / `张伟 #2`），唯一姓名不带编号；
id 永不复用，换座、导出、关系引用都保持稳定。

### 儿童椅

- 登记为儿童的宾客：座位以三角形童椅标记渲染，仍占一个席位。
- 未登记的婴幼儿：在桌详情中添加「儿童椅占位」，占 1 个容量、默认锁定，自动排座不会移动。

### 忌口与席位独立存储

IndexedDB 有两个 store：

- `projects`：场地、桌、宾客、关系、偏好、座位分配
- `dietary`：**忌口独立存储**，按 `guestId` 建索引

换座 / 撤销 / 重新自动排座只改 `assignments`，不触碰忌口；删除宾客也保留忌口记录。
导出桌卡（可打印 HTML，离线下载）时始终从 `dietary` 读取，因此换座后忌口不会丢失。
未入座宾客可选择一并导出（标注「未排座」）。

### 场地几何（仅几何检查，非安全认证）

- 桌位支持圆桌（圆）与长桌（轴对齐矩形），按真实形状与禁止占用多边形做相交检测：
  圆心/顶点在内、多边形顶点在桌内、边穿桌三类情况都覆盖。
- 项目数据提供的禁止占用多边形：中央**过道**、两侧**消防出口缓冲区**、舞台前沿。
- 拖动桌子时实时检查：出界、压入禁占区、桌间重叠，问题在画布与检查器中标红。

> ⚠️ 多边形与检查仅为**几何占用判断**，不构成、也不声称通过任何消防安全认证或合规审查。

## 内置验证样例（`npm run test:logic`）

1. **常规样例**：两位同名「张伟」、周家三口家庭、刘洋/孙强避让、
   希望同桌与靠主桌偏好、主桌婴幼儿童椅占位、2 位未回复、1 位婉拒、1 个锁定座位。
2. **冲突无解样例**：家庭关系把三人绑为一组、组内又存在避让边（逻辑矛盾）；
   另有避让双方被分别锁定在同一桌（锁定冲突）。求解器返回 infeasible，
   诊断器同时报出两类原因。

验证脚本覆盖 46 项断言：硬约束满足、无解诊断、儿童椅占容量且不被移动、
未回复两种策略、婉拒不入座、锁定保留、手工/自动方案代价比较、
撤销链（手工→应用自动方案→逐步撤销）、忌口跨多次换座仍出现在桌卡、
同名编号稳定、禁止多边形几何检查与「最近合法位置」。

## 目录

```
src/
  types.ts               领域模型
  solver/
    model.ts             MILP 建模 + 求解结果解释 + 任意方案打分 + 无解诊断（平台无关）
    solver.worker.ts     Worker 入口（glpk.js 内嵌 wasm，离线）
    client.ts            Worker 客户端
  lib/
    db.ts                IndexedDB（projects / dietary 双 store）
    actions.ts           手工排座纯函数（锁定拦截、换位、童椅、关系、偏好）
    geometry.ts          圆/矩形 × 多边形、出界、重叠几何检查
    placecards.ts        桌卡 HTML 构建与离线下载
    history.ts           撤销栈
    samples.ts           常规样例 + 无解样例
    ids.ts               uid 与同名稳定编号
  ui/                    React 组件（侧栏 / Konva 画布 / 检查器 / 对比卡）
scripts/validate-logic.ts  46 项逻辑验证
```
